# Game Notes Page

The Notes page can be accessed from the second button from the left under the current game info on the main page. Notes is a good way to set up important notes and reminders for the current game.

Simply select the **+** button or press **Y** to create a new note. Within the dialog, you enter the title (optional), the note text, the tag (category to organize it into), the color, and whether or not you want to set up reminders.

Once a note is created, you can edit it by simply pressing **A** on it. And when editing it, you can mark it as complete to organize it under a special completed category list. This is useful if you are using notes to set up goals of some sort that you want to check off.

## Setting Reminders

When you add or edit notes, you are able to set up a reminder. In the add/edit dialog, simply toggle the reminder button to either **Once** or **Every**. Once means the reminder only reminds you once, and then it is disarmed and no longer reminds you again. Every means a reminder will be shown on a recurring basis over and over until you disable it yourself.

Once either of these is selected, you can select the amount of time for it to remind you. Either select from the defaults or select the **Custom** option. For Custom, you enter the number in the field that appears and then, to the right of it, select min, hours, or days. So if you really wanted to, you can have it remind you about something every 7 days, for example.

If using a recurring reminder, you can disarm it by editing that note and then toggling **Every** to **Off**. Marking it complete will also disarm the reminder. When a reminder fires, it sends a notification to your Notifications bell and also fires a toast that you can see even when playing your game.

## What happens if I set a reminder for one game and switch to another?

While notes and their reminders are saved per game, they are based on wall-clock time, so nothing will be skewed. So if you set up a reminder to go off in Xenoblade in two hours, it will still fire in two hours even if you played other games in between, assuming the game is open by then. If it isn't, it will fire immediately upon switching to Xenoblade, as the time will be overdue.
