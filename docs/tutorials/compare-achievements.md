# Compare Page (Achievements)

The Compare page allows you to see where you stand against friends or strangers. It compares points, unlocks, RetroPoints and whether or not it was completed.

You are able to compare achievements directly by sorting them into four categories: **All**, **Gains**, **Losses**, and **Shared**. All just shows all of the achievements and marks the ones you don't have compared to them with a red bar. If you have an achievement but they don't, it shows up as a green bar. And if neutral, no bar at all.
