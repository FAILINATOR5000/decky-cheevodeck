# Leaderboards Page (List)

The Leaderboards page shows a list of the leaderboards available for the specified game. It can be accessed by selecting the sixth button under the current game info on the main page, by viewing it for a game from the [Game Info](game-info.md) page, or by viewing it for a friend's game in their [Profile](profile.md) page.

The list updates every 24 hours, so new leaderboards will show up during the next refresh.
