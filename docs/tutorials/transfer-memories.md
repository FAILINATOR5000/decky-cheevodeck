# Transfer Page (Memories)

This tool allows you to transfer your memories from one machine to another, either replacing them in full or merging them with existing memories. It's also a useful tool to back them up.

Simply choose where to save it. Then, import it on the other machine. If **Replace My Library** is off, it will simply merge in the memories you do not already have. If on, your memories are first deleted and then replaced with the imported ones.
