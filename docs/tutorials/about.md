# About Page

The About page contains information about the current version of CheevoDeck, as well as a button to check for updates. Updates are usually checked twice daily, but if you hear about an update release and want it now, you can select the **Check for Updates** button. Then, follow the on-page instructions, and you are good to go!

You can also find the **Add Updater to Desktop** button here. This adds a convenient **Update CheevoDeck** link on your desktop, which is an easy double-click way to update it as well.

Whenever an update is detected, whether it be automatic or manual, the About page will provide the ability to copy the link for the download, download the zip, or add the desktop updater. See the [Updating CheevoDeck](../../README.md#updating-cheevodeck) section for more information.
