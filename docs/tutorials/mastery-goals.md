# Mastery Goals Page

The Mastery Goals page will allow you to make unique and specific goals for completion or mastery, view the progress, as well as info for each game in your list. This goal could be anything. It could be "Zelda Games", "Xeno-Style Games", "My Childhood Games", "Cool JRPGs", or even "Barbie Games". The customizations and possibilities are endless. And the best part is, once you make a goal, progress is tracked for the set of games as a whole.

## Getting Started

To start a Mastery Goal, simply select the **New Goal** button on the main section. It will then ask for a name for the goal. For example, let's call this one "Favorite Zelda Games". Once you enter the name, it will be added to your list of goals below. Select it to enter the goal section.

Once in the goal section, you will see the title of your goal at the top. Notice it will say "0 games" because you have not added games yet to your goal. To add them, select the **Add Game** button to open the chooser. Select the system for the game you want to add. In this example, select **NES/Famicom**. Then you can either scroll down the list of games or search for the game (which is much easier). For example, search "Zelda", and you should see a list of the Zelda games for NES.

Now, you can select multiple games to add to your goal. Think of it as a shopping cart that you add your games to. Now if you want to add Zelda games from other systems, you can go to the top of the chooser, then select **Consoles** to go back to the console list, and then select the new console and new games there. To commit or add all of the games you selected, simply press **B** to close the dialog.

Once the dialog closes, you will now see all of the games you added below for your current Mastery Goal. And your total progress for the set of games as a whole shows at the top. Your games are organized by console by default, but you can change this by toggling **View**. Also, you can toggle **Sort** between **Manual**, **Recently Added**, and **Oldest Added**.

When on a game, you can press the associated shortcut button shown in the page to either view info, add a note, or re-order it in your list (provided you have manual sort on).
