# Social Hub Page: News & Events

The News & Events section of the Social Hub page offers everything you need to stay up to date with the latest RA news & magazine, track special events & the Achievement of the Week, as well as view the latest sets & revisions. There are three tabs in this section which contain everything you need to stay up to date: **News**, **Events**, and **Set Feed**.

## News

This is where you can view the latest news feed from RetroAchievements. Select any news card to be brought to that article. At the very top of this section is the **RetroAchievements Magazine** button. This will bring you to the latest magazine issue.

## Events

This not only will show the latest events, but you will be able to keep track of them here as well. Pressing **X** (or the associated button for your controller) will track and untrack the selected event in the list, putting it in a special list for you where you can keep an eye on a handful of events, organize them by giving them "tags" or categories, and even add notes to them.

To access your tracked events, select the button with the pin icon to view them. Press the same button to toggle back to list view. Tracking is completely optional, and you can still keep track of events in the default list format instead.

Whether in tracked or list view, you will be able to view the event, progress, etc. by selecting it with **A**. Not all events are the same, and some are checklist style, where you will be able to mark off whether each item is complete or not.

Next to the pin/list toggle button is the **Achievement of the Week** button, where you can view it, along with other stats and comments.

## Set Feed

The Set Feed tab contains sub-tabs where you can view the latest sets as well as set revisions. Selecting them will bring you to the [Game Info](game-info.md) page, where you can view information about the set/game, as well as comments.
