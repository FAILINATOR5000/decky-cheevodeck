# Game Info Page

The Game Info page offers extended information for a game. In addition to showing all of the achievements for the game and info, you can view info such as publisher, genre, release date, [leaderboards](leaderboards-list.md), and more.

At the top of the page, you can toggle through the different images for the game with **L1** and **R1**. Pressing **A** on any of the standard images will bring you to the game's information page at RetroAchievements.org. Useful if you want to add it to your [Want to Play](want-to-play.md) list. If you press **A** on the slide with the video icon, it will send you to YouTube with a list of videos for that game, which is useful if you are curious about how it looks and plays.

There are three tabs: Achievements, Comments, and Hashes/Patches.

- **Achievements:** Simply a list of achievements for the set.
- **Comments:** This is the comments section for this game set, where you can post, subscribe to (where you will be notified when someone posts here), or view comments.
- **Hashes/Patches:** Shows which game hashes are compatible with RetroAchievements, as well as providing a patch download for special games like ROM hacks.
