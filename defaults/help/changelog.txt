CheevoDeck {{VERSION}}

This one is mostly repairs and refinements for Cheevo Check and the Steam library badges feature.

<b>What's New</b>

- The <b>About</b> button in the Quick Menu now shows a small, glowing dot when an update is available.

<b>What's Fixed</b>

- Cheevo Check recognizes the rest of EmuDeck's ROM folder names now, including the regional ones. This allows full coverage and integration with libraries for users who use EmuDeck.

- For Cheevo Check, cue sheets are read properly now, instead of using the old educated guess algorithm. Single .bin games were sometimes ignored, but not anymore!

- The library badge waits a little longer for RetroAchievements before it gives up, so a slow connection is more likely to show your progress, instead of the fallback achievement count.

- The library badge no longer flashes the previous game's progress for a moment when you go straight from one game page to another.
